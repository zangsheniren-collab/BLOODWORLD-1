# BLOODWORLD // BULLET HELL — UPDATE 0.7

スマートフォン向けオフライン弾幕バトル試作版。GitHubリポジトリ直下へ全ファイルを配置します。

## 今回の更新

### 既存3キャラクターの弾幕再設計
- **花森 鈴音（敵）**：HPを450へ調整。枯葉・落ち葉の意匠を保ちつつ、プレイヤーの移動方向を読む追従扇弾、移動先を予告してから弾ける落葉陣、四辺からランダムに迫る弾幕を追加。
- **蕾 琥晴**：HPを330へ調整。斬撃線の中心と角度がプレイヤーの位置に応じて変わる追閃、予告付き落雷標、四方からの乱雷を追加。
- **柏原 柚花（ユズ）**：HPを290へ調整。追従ハート弾、四辺からの急接近、着弾後に分裂する弾、移動先を囲むハート陣を追加。
- この3人は弾幕の選択順を毎回ランダム化し、同じ攻撃の並びを覚えるだけでは回避できないように変更。

### 新キャラクター：オグレス・リリィ
- 活動名：オーガ・リリィ／ランク：ロード／所属：アーセナル。
- HP540、全7種類の専用弾幕。
- 追従扇弾、予告付き生成陣、予告斬撃、飛翔中に分裂する刻印弾、四辺からの武装群、双翼ユニット風の追撃、三点同時の最終生成陣を使用。
- 刻印弾の特殊効果として、命中時に短時間だけプレイヤーの移動速度を低下させる弾を実装。

### エンジン変更
- `hunterFan`：プレイヤーの位置・移動傾向を予測して扇状に発射。
- `randomEdges`：上下左右のランダムな端からプレイヤー付近へ向けて発射。
- `playerBurst`：プレイヤーの移動先付近に予告を出し、時間差で放射状に弾を展開。
- `slashHunt`：プレイヤー付近を中心に角度を変えた予告斬撃を発生。
- `splitFan`：飛翔途中で複数の弾へ分裂。
- 既存のHP・回避操作・アイテム・難易度設定は維持。

## 弾幕バランスについて
攻撃は予告表示や弾速の差を設け、完全な運任せではなく「見てから移動すれば避けられる」ことを重視しています。端末サイズ・処理速度によって体感難易度が変わるため、NORMALから確認してください。

- `engine.js`：弾幕生成・描画・当たり判定
- `main.js`：ゲーム進行・入力・キャラクター固有処理
- `ogres_lily.json`：オグレス・リリィのキャラクター設定

# BLOODWORLD BULLET HELL

スマートフォン向け弾幕バトル試作版。GitHubへファイルを個別アップロードしやすいよう、全ファイルをリポジトリ直下に置く構成です。

## GitHubへのアップロード
このZIPを展開し、中のファイルをすべてリポジトリ直下（mainブランチの一番上）へアップロードしてください。フォルダを作る必要はありません。
既存の同名ファイルは上書きしてください。古い構成の `css/`、`js/`、`data/` フォルダが残っていても、この版は参照しません。

## 起動
GitHub Pagesを有効にしている場合、反映後に公開URLを開いてください。反映には数分かかる場合があります。

## ファイル
- index.html：画面構成
- style.css：デザイン
- data.js：キャラクター・弾幕データ
- engine.js：戦闘エンジン
- main.js：画面と操作
- hanamori_suzune.json / photo_candray.json：キャラクター資料

これは初期プロトタイプです。各種数値やACT・ITEM・MERCYは今後調整します。


## 更新内容（BATTLE UPDATE 0.2）
- 敵ターンを長く調整。NORMALは約10秒が基本で、敵HP低下時はさらに延長します。
- 敵HPが約2/3以下になると第2段階、約1/3以下で最終段階に移行します。
- 段階に応じて弾幕の種類、弾数、速度、発射間隔が増加します。
- 雨、交差、掃射、ジグザグ、円形、扇状などの弾幕を追加しました。
- 行動ボタンは押した直後にロックされ、1ターン中の連続攻撃を防ぎます。
- 回避エリアを広げ、ドラッグ範囲と仮想スティックの反応を改善しました。

弾幕や難易度は `data.js`、弾幕の動きは `engine.js`、ターン進行と操作は `main.js` で管理します。

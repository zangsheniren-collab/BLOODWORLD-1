## UPDATE 0.12：飛雷走過・運ボス・コンビモード

### 新敵キャラクター：飛雷 走過
- HP600／ドミナント。銀白色と青白い雷光をイメージしたレーザー主体の敵。
- 最大HPから100ダメージ受けるごとに専用の弾幕段階が切り替わる（全6段階）。
- ジグザグ状の雷光線、予測線を表示してから時間差で連続発生する光線、移動する細いレーザー、回転レーザー、複数の光条をつないだ雷網を使用。
- 残りHP70以下では「禁速・刹那連光」へ移行。短い間隔でレーザーを連続発射する最終段階。
- 詳細設定は `hirai_souka.json` に収録。

### 新敵キャラクター：オラクル・ダイス（運ボス）
- HP760／ロード。既存の敵キャラクターが持つ弾幕をランダムに借りて戦うオリジナルボス。
- 戦闘開始時と、その後の敵ターンごとに弾幕担当キャラクターを抽選。
- 直前のターンと同じキャラクターは連続で選ばれない。抽選された敵の通常・中盤・最終段階の弾幕からランダムに使用する。
- 飛雷走過も抽選対象に含まれる。詳細設定は `oracle_dice.json` に収録。

### 新モード：COMBO／コンビモード
- タイトル画面でSOLO／COMBOを選択。
- COMBOでは敵キャラクターを2人、自由に選択できる。同じキャラクターの重複選択は自動で別キャラクターへ変更。
- 2人分のHPを合算したチームHPで戦い、先に1人目のHPを削り切ると、残った敵との戦闘が続く。
- 2人の弾幕パターンを交互に組み合わせ、同じ回避ターン中に両方の攻撃が現れる。
- 単独戦より弾幕密度をさらに約28%抑え、弾速も約7%抑制。攻撃の種類を増やしつつ、回避の余地を確保。
- コンビに柚花が含まれる場合、柚花の最終自爆技を独立した最終ターンとして処理し、その後は相方との戦闘が続く。
- コンビにオラクル・ダイスが含まれる場合、その枠も毎ターン異なる敵の弾幕を抽選する。

### エンジン変更
- `hunterFan`：プレイヤーの位置・移動傾向を予測して扇状に発射。
- `randomEdges`：上下左右のランダムな端からプレイヤー付近へ向けて発射。
- `playerBurst`：プレイヤーの移動先付近に予告を出し、時間差で放射状に弾を展開。
- `slashHunt`：プレイヤー付近を中心に角度を変えた予告斬撃を発生。
- `splitFan`：飛翔途中で複数の弾へ分裂。
- 既存のHP・回避操作・アイテム・難易度設定は維持。

## 弾幕バランスについて
攻撃は予告表示や弾速の差を設け、完全な運任せではなく「見てから移動すれば避けられる」ことを重視しています。端末サイズ・処理速度によって体感難易度が変わるため、NORMALから確認してください。

## UPDATE 0.10：攻撃力・難易度バランス調整

- 花森 鈴音（自操作キャラ）の攻撃力を18から36へ変更（2倍）。
- 敵HPはEASYを基準値とし、難易度が1段階上がるごとに1.3倍。
- 敵の攻撃ダメージはEASY基準で難易度が1段階上がるごとに1.2倍。
- 最高難易度INSANEでは、敵の攻撃ダメージにさらに+5。
- INSANEでは敵HPにさらに+100。ただし最終HPは800を上限とする。

| 難易度 | 敵HP倍率（EASY基準） | 敵攻撃倍率（EASY基準） | 追加補正 |
|---|---:|---:|---:|
| EASY | 1.0倍 | 1.0倍 | なし |
| NORMAL | 1.3倍 | 1.2倍 | なし |
| HARD | 1.69倍 | 1.44倍 | なし |
| INSANE | 2.197倍 | 1.728倍 | HP+100／攻撃ダメージ+5 |

※敵HPは各キャラクターの設定HPをEASY基準値として計算し、INSANE補正適用後に800で上限処理します。

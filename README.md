# BLOODWORLD BULLET HELL

BLOODWORLDを題材にした、オフライン対応のスマートフォン向け弾幕バトル試作版です。

## 起動方法
- `index.html` をブラウザで開くと起動します。
- ネット接続や外部ライブラリは不要です（フォントの外部読み込みを除きます。オフライン時は端末標準フォントにフォールバックします）。
- GitHub Pagesで公開する場合は、このフォルダの中身をリポジトリ直下にアップロードし、Settings → Pages → Deploy from a branch → main / root を選びます。

## 現在の収録キャラクター
- プレイヤー：花森 鈴音（仮ステータス・仮画像）
- 敵：フォト・キャンドレイ（仮ステータス・仮画像）

## 操作
- 敵ターン中：戦闘枠を指でなぞって魂を移動。
- 戦闘枠下の案内をタップすると、ドラッグ操作と仮想スティック表示を切り替えます。
- プレイヤーターン：FIGHT / ACT / ITEM / MERCY を選択。

## 拡張の基本
- キャラクターの基本データ：`js/data.js`
- キャラクター資料JSON：`data/characters/`
- 弾幕パターン：`js/data.js` の `patterns`
- 弾幕生成処理：`js/engine.js`
- 画像置き場：`assets/characters/` など

画像を受け取ったら `assets/characters/` に配置し、キャラクターデータの `image` と表示処理を接続する予定です。

## 注意
これは最初のプレイ可能な土台です。ステータス・攻撃力・敵HP・弾幕バランスは仮値です。MERCY、ACT、アイテム効果も今後のアップデートで本格化します。

# BLOODWORLD // BULLET HELL — UPDATE 0.4

スマートフォン向けオフライン弾幕バトル試作版。全ファイルをGitHubリポジトリ直下へ置く構成です。

## 今回の更新
- 操作キャラクターにハンナ・ミリーを追加。HP38、攻撃力7、所持アイテムなしの弱めのキャラクターです。
- ミリー専用ACT「香りを隠す」で、次の敵ターンの被ダメージを少し軽減できます。
- 敵キャラクターにメルリ・アールを追加。HP360、通常より長い弾幕ターン、HP低下に応じた追加パターンを持ちます。
- 水泡、掃射、渦、カッター、衝撃波、レーザーなどの弾幕を追加。
- 画面上にレーザー予告を表示してから攻撃判定が発生します。

## UPDATE 0.13：姫乃・追加操作キャラクター・ENEMY MODE

### 新敵キャラクター：姫乃（雪の狐姫／ルピナス）
- ランク：ドミナント／所属：威嚇射撃／18歳／身長168cm／EASY基準HP560。
- 白銀の氷柱・小型結晶・大型氷塊をテーマにした9種類の弾幕を使用。
- 氷弾が命中するとハートが青く変化し、0.2秒間だけ操作不能になる。
- **幻覚**：姫乃にダメージを与えた後、姫乃の凍結弾で動きを止められると、次のターンに幻覚弾幕へ移行。
- **吹雪**：白い吹雪を模した弾幕で画面を覆う。設定上の冷気は約-10℃。
- **氷鏡**：姫乃への攻撃ごとに反射判定。通常攻撃は70%、熱属性攻撃は50%の確率で反射。コンビ戦で姫乃が攻撃対象になっている場合も有効。
- **過冷**：水蒸気を氷晶に変えるイメージの分裂氷弾幕。ゲーム上は水場の環境判定までは行わず、氷晶弾幕として再現。
- **アイスプラネット**：最終段階で3ロルかけて展開準備を行い、3ロル目に氷のドームを思わせる巨大な予告と氷柱弾幕・余波を発生。走過とのコンビ戦でも3ロルの準備カウントに対応。
- 詳細設定（容姿・性格・能力・背景）は `himeno_hime.json` に収録。

### 飛雷走過との専用コンビ強化
- 走過と姫乃の2人をコンビに選ぶと「雪狐姫×雷速」の専用共鳴が発動。
- 通常のコンビ戦より弾幕密度・弾速・威力が大きく上昇。2人の弾幕を交互に組み合わせる。

### 操作キャラクターを3体追加
既存の敵キャラクターから、次の3名を操作可能にしました。
- **飛雷 走過**：HP138／攻撃27。能力「電迅・刹那」は安全な位置へ転位し、約0.76秒間の被弾を防ぐ。専用アイテム「予備バッテリー」2個で能力回数を回復。
- **柏原 柚花（ユズ）**：HP132／攻撃29。能力「テンポジャック♡」は次の敵ターンの弾速を38%低下させ、自身の移動速度を一時上昇。専用アイテム「鬼火チャーム♡」2個で次の被ダメージを55%軽減。
- **蕾 琥晴**：HP145／攻撃31。能力「残雷・瞬断」は周囲の弾幕を切り払い、敵へ固定24ダメージ。専用アイテム「返し鞘の留め具」2個で次の通常攻撃を2倍に強化。
- 薬品・回復薬は花森鈴音の専売特許として、追加3キャラには回復薬を持たせていません。
- **ハンナ・ミリーは最弱のまま**。HP38／攻撃7／アイテムなしを維持。

### 新しい隠しモード：ENEMY MODE
- 最高難易度 **INSANE** で敵キャラクターを1人以上撃破すると解放。
- SOLOまたはCOMBOで勝利した場合に解放条件を満たす。MERCYによる終了は撃破扱いにならない。
- 解放後、タイトル画面のMODEからENEMYを選択し、敵キャラクター14名の中から操作キャラクターを選ぶ。
- 自分が敵キャラクターとなって弾幕を放ち、自動で逃げ回るハートを攻撃する。
- 8回の攻撃ターン以内にハートのHPを0にできればクリア。
- 解放状態は同じブラウザのローカルストレージに保存されます。ブラウザデータを削除した場合や別端末では解放状態は共有されません。

## UPDATE 0.12：飛雷走過・運ボス・コンビモード

### 新敵キャラクター：飛雷 走過
- HP600／ドミナント。銀白色と青白い雷光をイメージしたレーザー主体の敵。
- 最大HPから100ダメージ受けるごとに専用の弾幕段階が切り替わる（全6段階）。
- ジグザグ状の雷光線、予測線を表示してから時間差で連続発生する光線、移動する細いレーザー、回転レーザー、複数の光条をつないだ雷網を使用。
- 残りHP70以下では「禁速・刹那連光」へ移行。短い間隔でレーザーを連続発射する最終段階。
- 詳細設定は `hirai_souka.json` に収録。

### 新敵キャラクター：オラクル・ダイス（運ボス）
- HP760／ロード。既存の敵キャラクターが持つ弾幕をランダムに借りて戦うオリジナルボス。
- 戦闘開始時と、その後の敵ターンごとに弾幕担当キャラクターを抽選。
- 直前のターンと同じキャラクターは連続で選ばれない。抽選された敵の通常・中盤・最終段階の弾幕からランダムに使用する。
- 飛雷走過も抽選対象に含まれる。詳細設定は `oracle_dice.json` に収録。

### 新モード：COMBO／コンビモード
- タイトル画面でSOLO／COMBOを選択。
- COMBOでは敵キャラクターを2人、自由に選択できる。同じキャラクターの重複選択は自動で別キャラクターへ変更。
- 2人分のHPを合算したチームHPで戦い、先に1人目のHPを削り切ると、残った敵との戦闘が続く。
- 2人の弾幕パターンを交互に組み合わせ、同じ回避ターン中に両方の攻撃が現れる。
- 単独戦より弾幕密度をさらに約28%抑え、弾速も約7%抑制。攻撃の種類を増やしつつ、回避の余地を確保。
- コンビに柚花が含まれる場合、柚花の最終自爆技を独立した最終ターンとして処理し、その後は相方との戦闘が続く。
- コンビにオラクル・ダイスが含まれる場合、その枠も毎ターン異なる敵の弾幕を抽選する。

### 更新・導入
ZIPを展開し、中のファイルをすべてリポジトリ直下へ配置してください。同名ファイルは上書きし、新規追加の `hirai_souka.json` と `oracle_dice.json` も配置してください。

### エンジン変更
- `hunterFan`：プレイヤーの位置・移動傾向を予測して扇状に発射。

## 弾幕バランスについて
攻撃は予告表示や弾速の差を設け、完全な運任せではなく「見てから移動すれば避けられる」ことを重視しています。端末サイズ・処理速度によって体感難易度が変わるため、NORMALから確認してください。

## UPDATE 0.10：攻撃力・難易度バランス調整

- 花森 鈴音（自操作キャラ）の攻撃力を18から36へ変更（2倍）。

|---|---:|---:|---:|

| NORMAL | 1.3倍 | 1.2倍 | なし |
| HARD | 1.69倍 | 1.44倍 | なし |
| INSANE | 2.197倍 | 1.728倍 | HP+100／攻撃ダメージ+5 |

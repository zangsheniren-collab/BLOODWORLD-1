# BLOODWORLD // BULLET HELL — UPDATE 0.6

スマートフォン向けオフライン弾幕バトル試作版。すべてのファイルをGitHubリポジトリ直下へ配置します。

## 今回の更新
- 花森鈴音（敵）を強化：HP 420、長い弾幕ターン、一度だけの全回復を強化。枯葉・落ち葉を中心にした弾幕に変更し、移動傾向に合わせて攻撃を切り替えます。
- 既存の全キャラクターに、それぞれ追加弾幕を2パターンずつ登録。
- 新しい敵キャラクター3名を追加：ハター・ウィキース、蕾 琥晴、柏原 柚花（ユズ）。
- ハター：左右から羽根を飛ばし、ステージの可動範囲を一時的に変化させます。
- 琥晴：刀の軌跡を表す斬撃レーザーを連続発射。命中時はノックバックします。
- ユズ：ハートの移動速度を遅く／速くする効果、銃弾風の弾幕、剣の斬撃を使用。HPが10%以下になると一度だけ高密度の最終弾幕を放ちます。
- 既存のITEM処理で二重に分岐していた箇所を整理し、アイテム使用処理へ到達できるよう修正。

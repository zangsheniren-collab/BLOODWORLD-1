# BLOODWORLD // BULLET HELL — UPDATE 0.3

スマートフォン向けオフライン弾幕バトル試作版。全ファイルをリポジトリ直下に置く構成です。

## 今回の更新
- ドラッグ操作を相対移動方式に変更。ハートそのものをタップせず、アリーナ内の離れた場所から指の移動量で操作できます。
- 敵選択に「ノール・ソルフォンシュ」を追加。
- ノール専用の剣・槍系弾幕を追加。
- HP低下に応じて弾幕が段階的に強化されます。
- 最終段階の終盤に特殊能力が発動し、魂を短時間拘束して固定ダメージを一度与えます（ゲーム内演出）。
